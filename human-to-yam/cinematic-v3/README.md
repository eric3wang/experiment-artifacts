# Human → YAM

[Play the visual-first demo](https://eric3wang.github.io/experiment-artifacts/human-to-yam/cinematic-v3/).

Full-screen action, three tasks, original soundtrack. Use the speaker button to
turn sound on. Credits and method are behind the info button.

This is a tighter edit of the existing verified Isaac recordings, using the same
YAM robot. Human videos stream from H2RBench. Scenes are manually reconstructed;
robot control is scripted. Packing covers the first block only. Playback is
retimed. Detailed results remain in the adjacent exocentric-v2 gallery.
