Method: Manually traced geometry and action waypoints, assumed scale and material properties, scripted inverse kinematics. These are approximate action reconstructions, not an automatic video-to-sim model or learned policy. Rigid objects use contact grasps. Cloth uses native PhysX particle cloth; cables use articulated rigid links. Flexible-object grasps use explicitly idealized attachments. Cable loop geometry is simplified. Cloth clips show only the first fold. Playback: each selected source segment and simulation spans a 20-second comparison cycle; intermediate events are not precisely time-aligned. Source clips retain their original speed labels (4× / 8× where present). Credits: DreamZero YAM gallery and REMODEL.
